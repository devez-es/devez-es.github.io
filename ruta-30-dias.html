Cómo aprender a programar desde cero en 30 días

Una ruta realista para principiantes, con herramientas gratuitas y una hora al día. No vas a ser un experto en un mes, pero sí tendrás bases sólidas y tu primer proyecto publicado.

Semana 1 · Bases
  • Instala Visual Studio Code y Python.
  • Aprende variables, tipos de datos, condicionales y bucles.
  • Objetivo: un programa que pida tu nombre y te salude.
Semana 2 · Funciones y mini proyectos
  • Funciones, listas y diccionarios.
  • Mini proyectos: una calculadora y el juego de adivinar el número.
Semana 3 · Terminal, Git y GitHub
  • Comandos básicos de la terminal.
  • Git: init, add, commit y push. Crea tu cuenta en GitHub.
  • Sube tus proyectos: serán tu primer portfolio.
Semana 4 · Tu primera web
  • HTML y CSS básicos.
  • Publícala gratis con GitHub Pages, como esta misma web.

Errores típicos que debes evitar

  • Ver tutoriales sin escribir código.
  • Saltar de lenguaje en lenguaje.
  • Compararte con otros: mide tu avance contra tu semana anterior.
